# 😷 Real-Time Face Mask Detector | كشف كمامات الوجه في الوقت اللحظي

مشروع ذكاء اصطناعي يعتمد على الرؤية الحاسوبية (Computer Vision) والتعلم العميق (Deep Learning) للتعرف على وجود كمامة الوجه من عدمه بشكل لحظي عبر كاميرا الويب (Webcam).

يستخدم المشروع نموذج شبكات عصبية التفافية (**CNN**) تم تدريبه لتصنيف الصور، مدمجاً مع خوارزمية **Haar Cascade** المخصصة لتحديد واكتشاف وجوه الأشخاص داخل الإطارات، ويُعرض عبر واجهة تفاعلية بسيطة باستعمال مكتبة **Gradio**.

---

## 🏗️ المكونات والتكنولوجيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| **TensorFlow / Keras** | بناء وتشغيل نموذج الـ CNN الخاص بالتصنيف |
| **OpenCV (cv2)** | التقاط إطارات الكاميرا، اكتشاف الوجوه (Bounding Boxes)، ومعالجة الصور |
| **Gradio** | بناء واجهة المستخدم وتأمين البث اللحظي من الكاميرا |
| **Requests** | تنزيل أوزان النموذج تلقائياً من Google Drive عند عدم وجودها محلياً |

---

## 🛠️ كيف يعمل المشروع؟

### 1. التحقق من ملف الأوزان
يفحص البرنامج وجود ملف الأوزان `mask_detector_weights.weights.h5` محلياً، وفي حال عدم وجوده يقوم بتنزيله تلقائياً وبشكل آمن من Google Drive.

### 2. بناء نموذج الـ CNN
- 3 طبقات التفافية (**Conv2D**) متبوعة بطبقات تجميع (**MaxPooling2D**).
- طبقات ربط كاملة (**Dense**) وطبقة إسقاط (**Dropout**) لمنع الإفراط في التكيف (Overfitting).
- طبقة تفعيل **Sigmoid** نهائية لإعطاء نسبة احتمالية بين 0 و1.

### 3. معالجة كل إطار (Frame Processing)
1. استلام الصورة من الكاميرا عبر Gradio وتحويلها إلى تدرج رمادي (Grayscale).
2. تطبيق `CascadeClassifier` لتحديد إحداثيات الوجه `(x, y, w, h)`.
3. قص منطقة الوجه وتعديل أبعادها إلى `128×128`، ثم تقسيم قيم البكسلات على `255.0` (Normalization).

### 4. التنبؤ وعرض النتيجة
- يمرَّر الوجه المجهّز إلى النموذج للحصول على نسبة التنبؤ.
- إذا كانت النسبة **> 0.5** → مربع أخضر + كتابة `Mask` مع نسبة التأكد.
- إذا كانت **أقل** → مربع أحمر + كتابة `No Mask`.

## 🚀 طريقة التشغيل

### المتطلبات الأولية
- Python 3.10 أو أحدث.

### 1. تثبيت المكتبات المطلوبة
```bash
pip install tensorflow opencv-python-headless gradio numpy requests
```
أو باستخدام ملف `requirements.txt` إن وُجد:
```bash
pip install -r requirements.txt
```

### 2. التشغيل محلياً
```bash
python app.py
```
بعد التشغيل سيظهر في آخر سطر:
```
Running on local URL: http://0.0.0.0:7860
```
افتح المتصفح على أحد الرابطين التاليين:
- http://localhost:7860
- http://127.0.0.1:7860

ثم اسمح للمتصفح بالوصول إلى الكاميرا للتأكد من عمل البث المباشر والتتبع اللحظي.

### 3. النشر على منصات السحاب (Railway / Hugging Face Spaces)
```bash
git add app.py requirements.txt
git commit -m "Deploy Mask Detector App"
git push origin main
```
اربط مستودع GitHub بحسابك على المنصة السحابية، وستتولى المنصة:
- قراءة متغير المنفذ `PORT`.
- تنزيل الأوزان تلقائياً.
- إطلاق التطبيق على رابط عام ينتهي بـ `.up.railway.app` أو `.hf.space`.
